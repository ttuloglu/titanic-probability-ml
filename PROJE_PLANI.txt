7.  Parch        : Gemideki ebeveyn/çocuk sayısı

9.  Fare         : Ödenen bilet ücreti
10. Cabin        : Kabin numarası
11. Embarked     : Biniş limanı (C=Cherbourg, Q=Queenstown, S=Southampton)
12. Survived     : Hayatta kalma durumu (0=hayır, 1=evet) - HEDEF DEĞİŞKEN

3.1. TEMEL OLASILIK
--------------------
HESAPLA:
P(Survived = 1) = (Hayatta kalan yolcu sayısı) / (Toplam yolcu sayısı)

YORUMLA:
- Genel hayatta kalma oranı nedir?
- Titanic faciasının şiddeti hakkında ne söyler?

3.2. KOŞULLU OLASILIK
--------------------
HESAPLA:
P(Survived = 1 | Sex = female) = P(Survived = 1 AND Sex = female) / P(Sex = female)

KARŞILAŞTIR:
- P(Survived = 1 | Sex = female) ile P(Survived = 1) arasındaki farkı incele
- Kadınların "önce kadınlar ve çocuklar" protokolünden nasıl etkilendiğini tartış
- Cinsiyetin hayatta kalma olasılığını nasıl değiştirdiğini açıkla

3.3. DİSCRETE RASTGELE DEĞİŞKEN (Pclass)
--------------------
Pclass'ı discrete random variable olarak ele al.

a) Probability Distribution Function (PDF) oluştur:
   P(Pclass = 1) = ?
   P(Pclass = 2) = ?
   P(Pclass = 3) = ?

   NOT: Toplamları 1 olmalı

b) Expected Value (Beklenen Değer):
   E[Pclass] = Σ (x * P(X = x))
   E[Pclass] = 1*P(Pclass=1) + 2*P(Pclass=2) + 3*P(Pclass=3)

c) Variance (Varyans):
   Var(X) = E[X²] - (E[X])²

d) YORUMLA:
   - "Expected ticket class" ne anlama gelir?
   - Hangi sınıf daha yaygın?
   - Varyans değeri dağılımın homojenliği hakkında ne söyler?

3.4. CONTINUOUS RASTGELE DEĞİŞKEN (Fare)
--------------------
Fare'ı continuous random variable olarak ele al.

a) Probability Distribution Function (PDF) tahmini:
   - Histogram kullanarak dağılımı görselleştir
   - KDE (Kernel Density Estimation) ile smooth PDF oluştur
   - Hangi dağılıma benzediğini yorumla (normal, log-normal, exponential?)

b) P(20 ≤ Fare < 100) hesapla:
   - Bu aralıktaki yolcu sayısını bul
   - Toplam yolcu sayısına böl

c) YORUMLA:
   - Bu olasılık yolcu demografisi hakkında ne söyler?
   - Ekonomik sınıf dağılımı hakkında ne anlıyoruz?
   - Çoğu yolcu düşük mü yoksa yüksek ücret mi ödemiş?

3.5. SEZGIYE AYKIRI BULGULAR (Counter-Intuitive)
--------------------

SORU 1:
P(Survived = 1 | Pclass = 1) ile P(Survived = 1 | Pclass = 3) karşılaştır

TARTIŞMA:
- Birinci sınıf yolcuların cankurtarma botlarına daha kolay erişimi var mıydı?
- Sonuçlar bu sezgiyi destekliyor mu?
- Sosyal sınıf hayatta kalma şansını nasıl etkiledi?

SORU 2:
P(Survived = 1 | Age < 10) ile P(Survived = 1 | Age > 50) karşılaştır

TARTIŞMA:
- Çocukların öncelikli olduğu sezgisi var
- Veriler bunu doğruluyor mu?
- Yaşlılar için hayatta kalma oranı beklentilere uygun mu?

4.1. İSTATİSTİKSEL VERİ ANALİZİ
--------------------

a) Descriptive Statistics (Tanımlayıcı İstatistikler):
   Her feature için:
   - Mean (Ortalama)
   - Variance (Varyans)
   - Standard Deviation (Standart Sapma)
   - Minimum
   - Maximum
   - Quartiles (Q1, Q2/Median, Q3)

   Kullan: data.describe()

b) Covariance ve Correlation Analizi:

   KORELASYON MATRİSİ:
   - Age, Fare, Survived arasındaki korelasyonları hesapla
   - Heatmap ile görselleştir

   POINT-BISERIAL CORRELATION (Binary değişkenler için):
   - Survived (binary) ile continuous features arasındaki korelasyon
   - Pozitif korelasyon: Yüksek değer → Hayatta kalma artışı
   - Negatif korelasyon: Yüksek değer → Hayatta kalma azalışı
   - Sıfır korelasyon: İlişki yok

   ÖNEMLİ YORUMLAR:
   - Hangi feature'lar survival ile en çok ilişkili?
   - Fare ve Pclass arasındaki ilişki nedir? (Negatif korelasyon beklenir)
   - Age ve Survival arasındaki ilişki var mı?

4.2. MODEL EĞİTİMİ
--------------------

ADIMLAR:

1) Feature Selection (Özellik Seçimi):
   Kullanılacak features: Pclass, Sex, Age, Fare
   Sebep: Bu değişkenler hem doluluk oranı yüksek hem de survival ile ilişkili

2) Categorical Encoding (Kategorik Kodlama):
   Sex: male=0, female=1
   Veya One-Hot Encoding kullanılabilir

3) Eksik Değer İşleme:
   Age: Median ile doldur
   Fare: Median ile doldur (gerekirse)

4) Train-Test Split:
   from sklearn.model_selection import train_test_split

   X = data[['Pclass', 'Sex', 'Age', 'Fare']]
   y = data['Survived']

   X_train, X_test, y_train, y_test = train_test_split(
       X, y, test_size=0.3, random_state=42
   )

   NOT: test_size=0.3 → %70 eğitim, %30 test
   random_state=42 → Tekrarlanabilirlik için sabit seed

5) Logistic Regression Modeli:
   from sklearn.linear_model import LogisticRegression

   model = LogisticRegression(max_iter=1000)
   model.fit(X_train, y_train)

   NOT: max_iter artırılabilir convergence için

4.3. MODEL DEĞERLENDİRME
--------------------

1) Tahminler:
   y_pred = model.predict(X_test)
   y_prob = model.predict_proba(X_test)[:, 1]

2) Accuracy Score:
   from sklearn.metrics import accuracy_score

   accuracy = accuracy_score(y_test, y_pred)
   print(f"Accuracy: {accuracy:.2%}")

   YORUMLA:
   - %70+ accuracy genellikle iyi kabul edilir
   - Baseline ile karşılaştır (her zaman 0 tahmin etsek accuracy ne olurdu?)

3) Confusion Matrix:
   from sklearn.metrics import confusion_matrix

   cm = confusion_matrix(y_test, y_pred)

   YAPISI:
                  Predicted
                  0      1
   Actual   0    TN     FP
            1    FN     TP

   - True Negative (TN): Doğru tahmin edilen ölümler
   - False Positive (FP): Yanlış hayatta tahmin edilenler
   - False Negative (FN): Yanlış öldü tahmin edilenler
   - True Positive (TP): Doğru hayatta tahmin edilenler

4.4. SONUÇLARIN YORUMLANMASI
--------------------

a) Predicted Probability (y_prob) ne anlama gelir?
   - Model her yolcu için [0, 1] arasında olasılık verir
   - 0.8 → %80 hayatta kalma ihtimali
   - 0.2 → %20 hayatta kalma ihtimali
   - Threshold (eşik) genellikle 0.5'tir

b) Model başarısını olasılıksal terimlerle tartış:
   - P(Tahmin doğru) = Accuracy
   - P(Gerçekten hayatta | Tahmin hayatta) = Precision
   - P(Tahmin hayatta | Gerçekten hayatta) = Recall/Sensitivity

c) Katsayılar (Coefficients) ve etkileri:
   - model.coef_ → Her feature'ın ağırlığı
   - Pozitif katsayı: O feature artarsa hayatta kalma ihtimali artar
   - Negatif katsayı: O feature artarsa hayatta kalma ihtimali azalır
   - Örnek: Sex=female pozitif katsayıya sahip olmalı

d) Accuracy'nin anlamı (conditional probability terimleriyle):
   - Accuracy düşükse model belirsizlik altında karar veriyor demektir
   - Neden %100 değil? → Veriler gürültülü, bazı bilgiler eksik
   - Hangi tür hatalar daha maliyetli? FP mi FN mi?

e) Tahmin belirsizliği:
   - Neden kesin sonuç veremiyoruz?
   - Titanic felaketinde tesadüfi faktörler rol oynadı mı?
   - Hangi bilgiler eksik? (Kabin konumu, bot erişimi, vs.)
