# Project Plan (English Summary)

## Project Title
Probability Meets Prediction: Introduction to Machine Learning with the Titanic Dataset

## Scope
The project combines:
1. Data preparation and exploratory analysis
2. Probability and random variables
3. Machine learning classification for survival prediction

## Dataset
The Titanic dataset includes passenger features such as class, sex, age, fare, embarkation port, family relations, and survival label (`Survived`).

## Workflow
1. Environment setup with Python, Jupyter, and core data science libraries
2. Data loading and structural inspection
3. Missing-value analysis and handling strategy
4. Distribution analysis for key variables (Age, Fare)
5. Variable type classification (discrete/continuous)
6. Basic and conditional probability calculations
7. Random variable analysis with expected value and variance
8. Correlation/statistical interpretation
9. Classification model training and evaluation

## Expected Deliverables
- Executed notebook(s)
- Probability and ML analysis report
- Interpretation of findings and model performance
