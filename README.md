# Titanic Probability and Machine Learning Project

This project combines probability concepts and introductory machine learning using the Titanic dataset.

## Included Files
- `titanic_analysis_english_executed.ipynb` : Executed notebook in English
- `titanic_report_english.pdf` : English project report
- `titanic_analizi_turkce_executed.ipynb` : Executed notebook in Turkish
- `titanic_rapor_turkce.pdf` : Turkish project report
- `PROJE_PLANI.txt` : Original project plan (Turkish)

## Topics Covered
- Data loading and preprocessing
- Missing-value handling
- Histogram and distribution analysis
- Discrete vs. continuous random variables
- Basic and conditional probabilities
- Correlation and statistical summaries
- Binary classification workflow for survival prediction

## Suggested Environment
- Python 3.8+
- Jupyter Notebook / JupyterLab
- pandas, numpy, matplotlib, seaborn, scikit-learn

## Open the Notebook
```bash
jupyter notebook titanic_analysis_english_executed.ipynb
```
